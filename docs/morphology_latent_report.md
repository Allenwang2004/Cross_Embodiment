# 身體參數與 BFM latent 的關係 —— 實驗報告

2026-09-28 · 凍結 Meta Motivo(FB-CPR, M-1),只調 latent z;成本 = bfm cost(1 − mean_t cos(B(s_t), B(g_t))),reference init,各身體自己的 torque 校準 XML。
數字一律寫成 `cost / 該 (clip, body) 的 z0 cost`:**1.0 = 什麼都不調,越低越好**。

---

## 建議的論文主軸

> **凍結 BFM 跨形體適應時,latent 的修正「可以在身體之間共享,不能在動作之間共享」。
> 沿著身體參數連續追蹤,得到的是一條有序、可內插的 β → latent 軌跡;
> 獨立搜尋得到的則是一團與 β 無關的點 —— 這也解釋了為什麼直接學 z0 → z 的映射會失敗。**

這是一篇「分析 + 方法」的論文。它的強項是 C3–C6(機制與結構),
「用身體參數加速新身體的適應」(C7)目前**只在身體庫附近成立**,應寫成有條件的結果。

證據強度標記:✅ 已證實 ⚠️ 部分成立 / 有條件 ❌ 已被推翻

## C1 ✅ 樸素轉移隨形體距離退化,BFM 自己的推論救不了

| 證據 | 數字 |
|---|---|
| 成人 → 目標身體的直線路徑上,z0 成本(相對成人) | 小孩 **2.14×**、只縮四肢 1.89×、變粗 1.59×、**放大 0.98×** |
| BFM 對「重定向到新身體的動作」做 tracking inference(平均成單一 z)| 中位數 **1.10× z0**,88 組只有 34 組比 z0 好 |

- 附帶發現:**放大身體幾乎不傷 z0,縮小身體傷很大**。
- 限制:retarget 推論是逐幀序列,平均成單一 z 會損失資訊;逐幀控制模式未測。
- 檔案:`outputs/morph_study/baselines.csv`、`continuation_{m2c,m2s,m2g,m2k}.txt`

## C3 ✅ latent 修正不能在動作之間共享

| 證據 | 數字 |
|---|---|
| 同一身體、把 clip A 搜到的 z 用在 clip B(headstand 10×10) | 中位數 **1.99× z0**,只有 **23%** 比不調好 |
| 40 個 headstand clip 各自最佳修正方向的兩兩 cos | **+0.003**(互相正交) |
| 監督式 MLP 擬合 32 個 clip 的目標 | 訓練集誤差 0.01°;**沒看過的 clip 預測離答案 34.6°,比 z0 的 29.7° 還遠**;rollout 1.018× |

- 意義:沿「動作」軸學 map 沒有東西可學 —— 這解釋了 9/22–9/26 所有 adapter 實驗的失敗。
- 檔案:`outputs/z_target_analysis/`

## C4 ✅ latent 修正可以在身體之間共享,且隨形體距離平滑衰減(四個形變方向都成立)

把在身體 i 搜到的 z 拿到身體 j 跑(連續追蹤的解,8 clips,中位數):

| 形體距離 ‖Δβ‖ | 整體縮小 m2c | 只縮四肢 m2s | 放大 m2g | 變粗 m2k |
|---|---|---|---|---|
| 0(自己) | 0.497 | 0.453 | 0.409 | 0.347 |
| 相鄰一步(≈0.06–0.09) | **0.657** | **0.634** | **0.517** | **0.536** |
| 兩步(≈0.12–0.19) | 0.787 | 0.729 | 0.665 | 0.701 |
| 最遠(0.47–0.75) | 0.989 | 0.986 | 1.019 | 0.949 |
| **對照:跨動作(C3)** | **1.99** | | | |

- 核心不對稱:**跨身體最壞退回「≈ 不調」,跨動作則主動有害**。

## C6 ✅(沿路徑)z\*(β) 可以內插,而且連續追蹤的解遠比獨立搜尋好內插

留一個身體出來,用路徑上其他身體的解預測它(零 rollout):

| | m2c | m2s | m2g | m2k |
|---|---|---|---|---|
| 該身體自己搜尋(上限) | 0.497 | 0.453 | 0.409 | 0.347 |
| **連續追蹤解,鄰居 slerp** | **0.596** | **0.559** | **0.489** | **0.528** |
| 連續追蹤解,最近鄰 | 0.673 | 0.659 | 0.552 | 0.603 |
| 獨立搜尋解,鄰居 slerp | 0.690 | 0.683 | 0.618 | 0.756 |
| slerp 勝過最近鄰(56 組中) | 40 | 44 | 34 | 33 |

- 平均相鄰兩身體的解**不會**掉進壞區;m2c 上零 rollout 拿回約 80% 的可得改善。
- 連續追蹤真正的價值在這裡:**不是找到更好的解(見 R1),而是找到彼此一致、可以學的解**。
- 檔案:`outputs/morph_study/interp_{m2c,m2s,m2g,m2k}.txt`

## C7 ⚠️ 用身體參數加速新身體的適應 —— 沿路徑很強,推廣到新身體很弱

**沿路徑(從相鄰身體的解出發)**,最遠端身體到達 0.5× z0:

| | m2c | m2s | m2g | m2k |
|---|---|---|---|---|
| 從 z0 | 248 | 128 | 256 | 136 |
| 從相鄰身體的解 | **16** | **24** | **16** | **32** |

但這個加速**以相鄰身體已經解過為前提**(路徑上游的搜尋成本不算在內)。

**推廣到不在任何路徑上的真實身體**(身體庫 = 4 條路徑共 36 個身體):

| 真實身體離最近庫身體 | 零 rollout 最佳預測 | 恢復的改善 | 暖啟動到 0.7× 的加速 | 暖啟動最終較好 |
|---|---|---|---|---|
| ≤ 0.2(7 身體,56 組) | 0.88–0.90 | 20–27% | 中位數 1.05×(見下註) | **40/56** |
| > 0.2(8 身體,64 組) | 0.96–1.0 | ≈ 0–12% | **1.0×** | 28/64 |

註(9/30):「暖啟動到 0.7× 的加速」原本寫 1.9×,是丟掉「兩種起點都沒降到 0.7×」的 10 組後算的;全部組都算(沒達標記 1×)是 1.05×(28 組變快、19 組持平、9 組變慢)。正式結果改用最後一欄:搜 1,024 次後暖啟動的最終成本較好的比例。

- 四種 β → latent 模型(最近鄰 / 核迴歸 / 切空間線性 / 共享 MLP)在真實身體上**差不多**;線性模型在遠處反而有害(1.27×)。
- **同樣 ‖Δβ‖ 下,沿路徑的轉移(0.52–0.79)遠好於離開路徑(~0.90)**:4 條路徑只覆蓋 8 維 β 空間中的 4 個方向,歐氏 β 距離不是好的鄰近度量。
- 已排除:child / giant / short_limbed / short_stocky 與路徑終點的 XML **完全相同**,不是泛化測試(若計入會得到假的 8–11× 加速),未列入上表。
- 檔案:`outputs/morph_study/map_real.csv`、`bnn_all.txt`、`bnn_all_lib.png`

## 已被推翻,不能寫的主張

**R1 ❌「連續追蹤找到比獨立搜尋更好的解」** —— 預算效應。在小孩身體上給獨立搜尋同樣總預算(4608 次):

```
中位數:獨立 512 次 0.524 → 單次長搜尋 0.287 → 連續追蹤 0.332;連續追蹤只贏長搜尋 1/8
```
另兩個對照(9 次重啟取最佳、在目標身體上原地連續 9 次)也收斂到同一處。從 z0 出發沒有被困住,只是**走得慢**。

**R2 ❌「每個 cell 的搜尋很便宜,不需要加速」** —— 只在 headstand(解離 z0 近)成立;move 要 700–1700 次。

**R3 ❌ 各種調整 ES 的做法能讓單一 adapter 學會所有動作**(row weighting、多頭、geodesic head、更長訓練、lambda_bc)—— 見 C3,沿動作軸沒有可學的函數。lambda_bc 能讓 adapter 記住訓練 clip,但誤差 8.3° 已足以讓 headstand 失敗。

## 限制

1. **8 個 clip**(每類別 1–2 個),每個搜尋只跑 1 個 seed。
2. 只有一個 BFM、一種人形骨架;身體變化限於 8 維縮放參數。
3. 只用 bfm cost 評估,沒有影片或任務成功率等質性證據。
4. 身體庫只有 4 條從成人出發的直線路徑。
5. 未測逐幀 latent 序列(BFMTrack 式控制)。

## 建議的下一步(依重要性)

1. **補身體庫的方向**:C7 失敗的主因是覆蓋不足。在 β 空間做格點或更多方向的路徑,再重測真實身體 —— 這決定「加速」能不能升級成主結果。
2. **擴大 clip 數到 20–40**,讓 C4–C6 的統計更站得住。
3. **換鄰近度量**:用「z0 成本對 β 的敏感度」加權的距離取代歐氏 β 距離。
4. 渲染 z0 vs 調整後的影片,作為質性圖。

### C8 ✅(新)latent 對身體的敏感度集中在四肢長度,且縮小遠比放大傷

z0 在路徑終點的成本 / 在成人上的成本(8 clips 中位數):

| 身體參數 | 縮到極值 | 放大到極值 | 路徑終點所需 latent 位移 |
|---|---|---|---|
| **腿長**(0.50 / 1.50) | **2.72×** | 1.28× | 51° / 47° |
| **手長**(0.55 / 1.40) | **1.68×** | 1.03× | 48° / 46° |
| 腿粗(0.70 / 1.30) | 1.29× | 1.07× | 50° / 35° |
| 軀幹長、頭、手粗、軀幹粗、頭粗 | 0.97–1.02× | 0.98–1.06× | 30–45° |

- 只有縮短腿的路徑,搜尋後仍明顯殘留(best/z0 0.78);其他方向搜尋後都能降到 0.3–0.5。
- 與 C1 的「放大不傷、縮小傷」一致,現在有逐維證據。
- 意義:β → latent 轉換的有效維度很低,實際上主要是「四肢長度」;這可以直接寫成論文的一個結論,也提示新身體的鄰近度量應該以四肢長度加權,而不是 8 維歐氏距離。

### C7 更新 ⚠️ 覆蓋變公平後,新身體的推廣有改善,但仍然弱

held-out 真實身體(排除 XML 與庫身體相同的 child / giant / short_limbed / short_stocky),零 rollout 預測恢復的改善比例:

| | 舊庫(4 條斜線,36 身體) | 新庫(+16 軸向,100 身體) |
|---|---|---|
| 核迴歸,全部 | 15% | **21%** |
| 核迴歸,遠(> 0.2) | 9% | **13%** |
| 切空間線性,近(≤ 0.2) | 4% | **33%** |
| 切空間線性,遠 | −108%(有害) | −11% |
| 核迴歸預測中位數(cost / z0) | 0.939 | **0.925** |

- 核迴歸 9/30 改為「修正量依 β 距離加權平均,再從 z0 走出去」(舊版把 latent 本身在球面上平均:14% / 28%,遠處 8% / 20%)。新舊逐格比較各贏一半,bootstrap 差異 95% 信賴區間 36 庫 [−5%, +7%]、100 庫 [−11%, +2%],差異在雜訊內。檔案:`outputs/morph_study/map_real_v2.txt`。
- 線性模型在軸向覆蓋下才變得可辨識,近處從無效變成與核迴歸相當(33%)。
- 暖啟動(以最近庫身體出發)幾乎沒變:搜 1,024 次後比冷啟動好的比例,近 **71% → 70%**、遠 **44% → 46%** —— 因為真實身體同時改變多維,**單軸路徑在歐氏距離上靠不近它們**,只有 4 個真實身體換到更近的鄰居。
- 結論:公平覆蓋讓「組合型」模型(核、線性)有了可學的東西,但距離「新身體零搜尋就能用」仍很遠(最好只拿回 ~30% 改善)。

### 更新後的建議

1. 論文主結果維持 C3–C6,**加入 C8**(逐維敏感度)作為一個乾淨、可解釋的發現。
2. C7 寫成有條件的結果:推廣半徑小(‖Δβ‖ ≲ 0.1–0.2),且需要在「四肢長度」方向上密集覆蓋。
3. 若要把 C7 升級成主結果,下一步是**只在四肢長度的 2–3 維做格點**(C8 顯示其他維幾乎無關),而不是繼續擴充 8 維;並用四肢長度加權的距離選鄰居。
